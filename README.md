# E-commerce Core 

## Описание
В рамках домашнего задания реализованы основные сущности для будущего интернет-магазина:
- класс `Product` с атрибутами `name`, `description`, `price`, `quantity`
- класс `Category` с атрибутами `name`, `description`, `products` (список объектов `Product`)
- атрибуты класса `Category`: `category_count` (количество категорий) и `product_count` (общее количество товаров во всех категориях), автоматически обновляемые при создании объектов.
