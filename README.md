# E-commerce Core 

## Описание
В рамках домашнего задания реализованы основные сущности для будущего интернет-магазина:
- класс `Product` с атрибутами `name`, `description`, `price`, `quantity`
- класс `Category` с атрибутами `name`, `description`, `products` (список объектов `Product`)
- атрибуты класса `Category`: `category_count` (количество категорий) и `product_count` (общее количество товаров во всех категориях), автоматически обновляемые при создании объектов.

## Установка и запуск
1. Убедитесь, что установлен Python 3.9+ и [Poetry](https://python-poetry.org/).
2. Склонируйте репозиторий и перейдите в директорию проекта.
3. Установите зависимости:
   ```bash
   poetry install
   
## Реализовано во втором задании
- Приватный атрибут списка товаров в `Category`
- Метод `add_product()` для добавления товара
- Геттер `products`, возвращающий строку с перечнем товаров
- Класс-метод `Product.new_product()` для создания из словаря
- Приватная цена с геттером и сеттером, проверка на положительное значение

## Реализовано в третьем задании
- Переопределён метод `__str__` для `Product` (формат: "Название, X руб. Остаток: X шт.")
- Переопределён метод `__str__` для `Category` (формат: "Название, количество продуктов: X шт.")
- Реализован магический метод `__add__` для `Product`, возвращающий сумму произведений цены на количество двух товаров.

## Реализовано в четвёртом задании
- Добавлены классы-наследники `Smartphone` (смартфоны) и `LawnGrass` (трава газонная).
- Ограничение сложения: товары можно складывать только одного класса (используется `type()`).
- В метод `Category.add_product()` добавлена проверка, что добавляемый объект является экземпляром `Product` или его наследником.

## Реализовано в пятом задании
- Создан абстрактный базовый класс `BaseProduct`, родительский для `Product`.
- Классы `Smartphone` и `LawnGrass` наследуются от `Product`.
- Добавлен класс-миксин `MixinLog`, который при создании объекта выводит в консоль имя класса и переданные параметры.
- Миксин включён в цепочку наследования `Product`.

## Реализовано в шестом задании
- В классе `Product` при попытке создать товар с нулевым количеством выбрасывается исключение `ValueError` с сообщением «Товар с нулевым количеством не может быть добавлен».
- В классе `Category` добавлен метод `average_price()`, вычисляющий среднюю цену товаров. Если товаров нет — возвращается 0 (обработка деления на ноль через `try/except`).
